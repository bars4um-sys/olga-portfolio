## 4. Проблемы и решения

| Проблема | Решение |
|----------|---------|
| Файл `data/Ссылка на образцы` казался пустым | Использовали `cat -v` для просмотра невидимых символов, обнаружена ссылка на Pinterest |
| Pinterest блокирует парсинг | Использовали curl с User-Agent, извлекли JSON-данные и скачали 6 образцов |
| Шрифты без woff2 (только otf/ttf) | Подключили через `format('opentype')` и `format('truetype')` с `font-display: swap` |
| Пробелы в путях к файлам | Использовали URL-encoding (`%20`) в HTML |
